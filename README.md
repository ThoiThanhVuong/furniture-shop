## 🎯 Giới Thiệu Dự Án

Các doanh nghiệp vừa và nhỏ (SME) thường xuyên gặp khó khăn trong việc vận hành: dữ liệu nằm rải rác ở nhiều file Excel, khó kiểm soát hàng tồn kho, quản lý tài chính thủ công hay việc tính lương nhân sự tốn quá nhiều thời gian. 

**Pocket Mini System** ra đời như một "chiếc túi vạn năng" giải quyết bài toán đó. Đây là một hệ thống **ERP Lite** mạnh mẽ giúp tập trung mọi luồng công việc vào một nền tảng duy nhất. Từ Quản lý Kho bãi, Nhân sự, Tài chính cho đến Đối tác – tất cả đều được thiết kế với giao diện tuyệt đẹp và trực quan.

🔥 **Điểm khác biệt lớn nhất:** Hệ thống được tích hợp sẵn **Trợ lý AI**, giúp bạn không chỉ "nhập liệu" mà còn nhận được những phân tích tự động, báo cáo thông minh và tự động hóa các quyết định kinh doanh.

## ✨ Các Tính Năng Cốt Lõi

Hệ thống được thiết kế thành 4 phân hệ (Modules) độc lập và 1 Trợ lý thông minh.

### 📦 1. Quản trị Kho (Inventory)
- **Quản lý danh mục & hàng hóa:** Theo dõi chi tiết từng mặt hàng, biến động giá, thông tin hình ảnh.
- **Quy trình Nhập - Xuất - Chuyển kho:** Quản lý chặt chẽ các phiếu nhập/xuất, cảnh báo hàng hóa tồn kho tới mức tối thiểu.
- **Kiểm kê định kỳ:** Giúp đối soát dữ liệu thực tế tại kho và trên hệ thống.
- **Lợi ích:** Ngăn ngừa thất thoát, tối ưu mức tồn kho, dễ dàng tra cứu vị trí và lịch sử của từng mặt hàng.

### 👥 2. Nhân sự (HRM)
- **Hồ sơ nhân viên:** Lưu trữ số hóa thông tin liên hệ, hợp đồng, lịch sử làm việc và thăng tiến.
- **Phân quyền đa cấp bậc:** Chức năng Role-based access control (RBAC) chi tiết, kiểm soát quyền hạn tới từng tính năng nhỏ nhất.
- **Chấm công & Tính lương:** Theo dõi ngày phép, đi trễ, tự động tính toán bảng lương (Payroll) nhanh chóng và chính xác.
- **Lợi ích:** Giảm tải 80% thời gian xử lý giấy tờ cho HR, minh bạch chính sách lương thưởng, số hóa toàn diện quy trình nhân sự.

### 🤝 3. Đối tác (Partners)
- **Khách hàng & Nhà cung cấp:** Quản lý tập trung thông tin, địa chỉ, lịch sử liên hệ.
- **Theo dõi công nợ:** Cảnh báo các khoản công nợ đến hạn, lịch sử thanh toán giữa doanh nghiệp và đối tác.
- **Cấp độ đối tác:** Phân loại VIP, khách hàng thân thiết, khách hàng tiềm năng.
- **Lợi ích:** Tăng cường mối quan hệ kinh doanh, không bao giờ bỏ sót lịch sử giao dịch và làm việc.

### 💰 4. Tài chính (Finance)
- **Sổ quỹ:** Theo dõi dòng tiền (Cash flow) chi tiết vào và ra.
- **Phiếu Thu / Chi:** Quản lý và phê duyệt mọi giao dịch tài chính phát sinh trong công ty.
- **Báo cáo kinh doanh:** Lợi nhuận, doanh thu tổng quan thể hiện bằng các biểu đồ trực quan, dễ hiểu.
- **Lợi ích:** Nắm bắt sức khỏe tài chính của doanh nghiệp theo thời gian thực (Real-time).

### 🤖 5. Trợ lý AI (AI Assistant)
- **Chatbot thông minh:** Tương tác, tra cứu thông tin hệ thống bằng ngôn ngữ tự nhiên.
- **Phân tích dữ liệu:** Tổng hợp doanh thu, dự báo hàng hóa sắp hết dựa trên chu kỳ bán hàng.
- **Tự động hóa:** Gợi ý tạo lệnh đề xuất nhập/xuất kho tự động thông minh.
- **Lợi ích:** Doanh nghiệp có ngay một "Giám đốc vận hành ảo" sẵn sàng tư vấn và giải đáp 24/7.

## 🏗 Kiến Trúc Kỹ Thuật & Công Nghệ

Pocket Mini System được xây dựng theo kiến trúc **Domain-Driven Design (DDD)** kết hợp **Clean Architecture** ở phía Backend, đảm bảo mã nguồn có khả năng mở rộng (scalable), dễ bảo trì (maintainable) và dễ dàng testing.

### 🖥 Giao diện (Frontend)
- **Framework:** Next.js 14 (Sử dụng App Router hiện đại).
- **Ngôn ngữ:** TypeScript đảm bảo an toàn kiểu dữ liệu (Type-safe).
- **Quản lý State:** Context API / Zustand / Redux (Tùy theo module).
- **Giao diện & UI/UX:** Tailwind CSS cho styling kết hợp với Framer Motion tạo ra các hiệu ứng chuyển động mượt mà.

### ⚙️ Máy chủ (Backend)
- **Framework:** NestJS - Framework Node.js hàng đầu cho ứng dụng cấp doanh nghiệp.
- **Cơ sở dữ liệu:** PostgreSQL mạnh mẽ, giao tiếp thông qua TypeORM.
- **Kiến trúc:** Phân tầng rõ rệt qua Domain, Application, Infrastructure, Presentation.
- **Bảo mật:** Authentication và Authorization qua NestJS/Passport, kết hợp JWT (JSON Web Tokens).
- **Trí tuệ nhân tạo:** Tích hợp sức mạnh của Gemini AI / OpenRouter API.

## 🚀 Hướng Dẫn Cài Đặt Nhanh

Hệ thống hỗ trợ khởi chạy toàn diện bằng Docker (khuyên dùng) để đảm bảo môi trường đồng nhất, tránh lỗi vặt và tối ưu hóa thời gian cài đặt.

### 📋 Yêu cầu hệ thống
- [Docker Desktop](https://www.docker.com/products/docker-desktop) và Docker Compose đã được cài đặt trên máy.
- *(Nếu chạy thủ công):* Cần cài đặt sẵn Node.js (v18+) và PostgreSQL (v14+).

### 🐳 Cách 1: Chạy với Docker (Khuyên dùng)
*Chỉ mất khoảng 2 phút để khởi chạy toàn bộ hệ thống.*

1. **Clone repository và di chuyển vào thư mục dự án:**
   ```bash
   git clone <your-repo-url>
   cd pocket-mini-system
   ```

2. **Thiết lập biến môi trường:**
   ```bash
   cp .env.example .env
   # Hãy mở file .env bằng trình soạn thảo và điền khóa GEMINI_API_KEY của bạn!
   ```

3. **Xây dựng và Khởi chạy hệ thống:**
   ```bash
   docker-compose -f docker-compose.dev.yml up --build -d
   ```

4. **Truy cập ứng dụng:**
   - **Frontend (Giao diện người dùng):** `http://localhost:3000`
   - **Backend API:** `http://localhost:3001/api`
   
   *(Lưu ý: Lần đầu khởi chạy có thể mất vài chục giây để hệ thống tự động khởi tạo CSDL và biên dịch ứng dụng).*

### 💻 Cách 2: Dành riêng cho Developers (Chạy thủ công)

<details>
<summary><b>👉 Nhấn vào đây để xem chi tiết hướng dẫn chạy môi trường Development thủ công</b></summary>
<br>

**1. Khởi tạo Database:**
Đảm bảo bạn đã có một server PostgreSQL đang chạy. Tạo database cho dự án, ví dụ đặt tên là `pocket_mini_db`.

**2. Khởi chạy Backend:**
Mở một cửa sổ Terminal mới (Terminal 1):
```bash
cd Backend
npm install
# Copy file .env mẫu
cp .env.example .env 
# Mở file .env và cập nhật DB_HOST, DB_USER, DB_PASSWORD, GEMINI_API_KEY...
npm run start:dev
```

**3. Khởi chạy Frontend:**
Mở một cửa sổ Terminal thứ hai (Terminal 2):
```bash
cd frontend
npm install
# Copy file .env mẫu
cp .env.local.example .env.local 
# Đảm bảo NEXT_PUBLIC_API_URL trỏ đúng về Backend (thường là http://localhost:3001)
npm run dev
```
</details>

## 🛑 Dừng / Tắt Ứng Dụng

- **Đối với Docker**: Mở terminal ở thư mục gốc dự án và chạy lệnh sau để tắt và xóa các container:
  ```bash
  docker-compose -f docker-compose.dev.yml down
  ```
- **Đối với chạy thủ công**: Nhấn tổ hợp phím `Ctrl + C` tại các cửa sổ terminal đang chạy và chọn `Y` (nếu được hỏi) để xác nhận tắt tiến trình.
